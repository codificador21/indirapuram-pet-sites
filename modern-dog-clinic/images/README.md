# Site images

To change a photo, replace the file with a new one using exactly the same name. No code changes needed.
If a file is missing, the site shows a neat placeholder instead.

Use JPG, keep each file under ~300 KB (compress at https://squoosh.app).

| Folder | File | Where it shows | Recommended size |
|---|---|---|---|
| `hero/` | `main.jpg` | Main photo at the top of the page | 1800 × 1000 |
| `gallery/` | `1.jpg … 5.jpg` | Photo gallery (1 is shown largest) | 1000 × 1000 (square) |
| `stories/` | `1.jpg, 2.jpg, 3.jpg` | Recovery story cards, in order | 800 × 600 (landscape) |
| `reviews/` | `1.jpg, 2.jpg, 3.jpg` | Pet photo next to each review, in order | 240 × 240 (square) |
| `social/` | `share.jpg` | Preview image when the link is shared on WhatsApp | exactly 1200 × 630 |

**All current photos are public-domain stock placeholders (see CREDITS.md).** Replace them with real photos of the business before launch.
